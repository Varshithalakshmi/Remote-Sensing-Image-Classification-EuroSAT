# Remote Sensing Image Classification Using EuroSAT

## Project Overview
This project focuses on classifying satellite images into different land-use and land-cover categories using deep learning.

## Dataset
EuroSAT RGB satellite image dataset.

The dataset contains 10 classes:
- Annual Crop
- Forest
- Herbaceous Vegetation
- Highway
- Industrial
- Pasture
- Permanent Crop
- Residential
- River
- Sea Lake

## Technologies
- Python
- Deep Learning
- TensorFlow / Keras
- CNN
- MobileNetV2
- Streamlit
- Git and GitHub
